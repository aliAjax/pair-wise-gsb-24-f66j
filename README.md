# hxwl-10 考古探方记录

遗址探方、地层关系与出土物坐标档案：从登记、装袋到封存的可续作依据链。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 校验与测试

```bash
npm run typecheck   # TypeScript 类型检查
npm run smoke       # 业务规则冒烟测试（坐标/排队/换版/审批/离线回传，42 项）
npm run build       # 生产构建
```

## 业务规则（封存依据链）

- **坐标落格**：出土物坐标必须落在所属探方网格内，出格记为坐标冲突，可修正；冲突未清零不能封存。
- **装袋限制**：取样袋只装同探方同地层、已登记且未运走的出土物；单袋上限 12 件 / 3000g。
- **超限排队不占袋号**：超限的装袋请求进入队列，结算时才按序发袋号（如 `T0203-③-001`）。
- **换版失效重算**：地层换版或封存申请建立/变更时，未封袋记录作废、出土物释放并自动生成重算排队单；已封袋保留原依据快照（地层版本 + 申请版次）。
- **断网本地先行**：断网时操作记入本地回传队列；回连后按袋号逐件合并，重复回传只入库一次；同一袋号两个窗口同时提交先到者生效（另开浏览器窗口即可复现）；写入失败后只重试未完成项（可勾选“模拟封口登记接口故障”验证）。
- **封存审批**：没有待处理袋（未封袋 + 排队单）且没有坐标冲突时申请才能通过，通过后探方锁定。
- **页面与导出同源**：封存申请页的“依据预览”和“导出封存依据（JSON）”使用同一选择器生成。

## 数据存储

- 每个浏览器窗口一份本地库（`localStorage`，按窗口编号隔离），模拟单机的本地记录。
- 远端库房档案库为跨窗口共享存储，用 Web Locks 保证互斥，用于演示双窗口并发与回连合并。
- “重置演示数据”可清空本地与远端，恢复示例记录（T0203 / T0204 / T0301）。
