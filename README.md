# hxwl-10 考古探方记录

探方 · 地层 · 出土物 · 取样袋 —— 可续作的封存依据链。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 业务规则

- **坐标落格**：出土物坐标必须落进所属探方 E/N 网格；网格调整导致越界即记为坐标冲突，冲突件不能装袋，逐件修正后才解除。
- **装袋**：取样袋只装同探方同地层、已登记且未运走的出土物；袋内件数（≤6）与总重（≤1200g）超上限即排队，排队与装袋阶段都不占袋号，袋号仅在封袋时分配。
- **依据快照**：封袋时记录「地层版本 · 申请版本 · 件数 · 总重 · 清单」快照。地层换版或封存申请变更时，未封袋记录失效并按新依据重算，已封袋保留原依据。
- **断网续作**：断网时所有记录只写本地（localStorage + outbox）；回连后按袋号逐件合并，幂等键 `袋号::出土物编号` 保证重复回传只入库一次。
- **并发与重试**：同一袋号两个窗口同时提交，远端先到者生效，后到窗口自动改发新号；写入失败后重试只补未完成项（另有标签页即真实第二窗口，远端库共享）。
- **封存门槛**：没有待处理袋（待封袋 / 排队件）且没有坐标冲突时，封存申请才能审批通过；通过后探方封存，禁止再登记、换版、调网格。
- **同一依据**：页面展示的封存依据摘要（FNV-1a digest）与导出 JSON 由同一函数 `buildSealingBasis` 生成，摘要一致。

## 目录结构

```
src/
  domain/    类型、常量、纯规则（rules.ts）、示例数据（seed.ts）
  store/     远端库模拟（remote.ts）、回连合并引擎（sync.ts）、
             状态转移（reducer.ts）、React 钩子（useArchive.ts）
  components/ 网格落位、登记、装袋、封存申请、断网回传等面板
scripts/
  selftest.mjs  业务规则自检（35 项场景断言）
```

## 校验

```bash
npm run typecheck   # TypeScript 类型检查
npm run selftest    # 规则自检：坐标/排队/换版重算/断网合并/先到者生效/失败重试/封存门槛/依据摘要
npm run build       # 生产构建
```
